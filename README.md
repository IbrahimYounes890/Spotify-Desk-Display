# Description
This desk display shows music analytics and album art, with touch input for more info. It is designed around Spotify and uses the Last FM API connected to a Spotify Account to get the information. This was for Display Week for HalfLife HackClub

# Parts Used:
* ESP-32 DEVKITC
* TTP223 touch sensor
* TFT Display Module


# Why was it made?
I made this because I always like knowing the song information, but I would always have to open up the app on my laptop and my phone, which would distract me constantly. This way, I wouldn't have to lose focus and have a chance of getting distracted.
